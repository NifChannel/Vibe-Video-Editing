# 本地 IndexTTS 配音

需要配音时，先执行 [配音依赖与自动安装](../../安装与外部依赖.md#tts)。由 Codex 自动检测硬件、安装官方项目与权重、选择兼容接口并写入 runtime.local.json，不要求用户填写路径。不要调用作者私有的 narrate.py、服务、音色注册或固定部署目录。

1. 保留用户定稿，将技术读音展开另存副本。文稿和输出放在当前项目中，长片按场景分段。
2. 读取实际取得版本的官方推理示例。用自动配置的 indextts_root 和独立环境执行该版本的 API/CLI；已有服务则先核对其真实接口。不要从旧环境猜测参数或端口。
3. 使用用户获准参考音频或上游明确许可的示例。未注册音色不能当作现成命名音色；增加参考音频不等于训练了模型。
4. 先合成短段，试听语言、读音、情绪、音色与速度，再批量生成。不覆盖已有输出，不修改系统 Python、驱动或其他模型环境。
5. 用 FFprobe 核对真实时长、采样率和音轨，以实际音频重新安排字幕、镜头和混音，不能用字符数当作精确时间轴。

环境或模型加载失败时报告真实原因，保留日志和成功产物。不自动上传文稿或参考声音到云服务。必要的合法参考音频、账号或权限确实无法自动获得时才请用户介入。
