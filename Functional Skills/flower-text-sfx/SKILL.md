# 花字音效

只在用户要求给花字加音效时加载。已有花字时直接使用确认过的成片、时间线或花字事件表。需要同时制作花字时，与 [Remotion 花字](../remotion-flower-text/SKILL.md) 联动，以实际渲染出的动效为准。给定稿补音效时沿用已确认的文字、画面和时码。

## 音效库

由 Codex 按[音效自动准备](../../安装与外部依赖.md#sfx)定位用户音效或下载所需合法音效，并写入 runtime.local.json 的 sfx_library，再从该目录检索。Mixkit 的 `.wav` 在 `mixkit.com`，适合扫过、落点和质感变化。Kenney 的 `.ogg` 在 `kenney_interface-sounds`，可试听短点击、轻提示等界面类声音。优先复用已认可的音色和使用规则，按实际试听判断素材。记录使用文件和来源，按各自许可处理原音效交接。换机和 CLAP 环境见 [安装与外部依赖](../../安装与外部依赖.md#sfx)。

## 匹配与对点

1. 从确认的花字事件提取词组、语义作用、动效、成片帧率、动画入场帧和动作落点。按需要做声音强调，普通字幕换页和弱重点可以留静。相同动效可以复用同类声色，避免连续抢口播。
2. 把语义作用和视觉动作转成声音描述。例如价格牌弹出可搜 `short soft UI pop, fast attack, no long tail`，横向滑入可搜 `quick airy whoosh, light and clean`。使用短英文描述声音的起音、长度、质感和力度。按 [CLAP 本地检索](references/clap-matching.md) 对本机音效排序，逐个试听前 3–5 个候选。环境不可用时按文件名、类别和试听筛选，记录实际采用的方法。
3. 在当前成片时间线上定位声音的主要瞬态。点击或撞击对齐字牌弹定、落地或最强强调帧。扫过声可从可见运动前沿起声，让声音峰值或收束对齐动效落点。按 `落点帧 ÷ 成片帧率 − 音源瞬态偏移秒数` 计算片段起点。截取片头静音或修整尾部时重新试听，保护实际起音。画面时序变化后重新对齐音效。
4. 把音效作为独立素材/轨道或单独的混音输入。在带口播和 BGM 的代表片段里试听，按对白清晰度、动效力度和邻近声音调整音量与尾音。把已存在的同类音效计入混音，避免叠放两次。按需要交付独立音效素材或音效分轨，避免与已包含同一音效的混音叠放。

将使用的花字事件、落点帧、源文件、源入出点、成片起点、增益及选声理由写入项目级时间线或音效清单。导出后抽听密集口播、重点入场和尾音衔接，确认成片实际使用了选中的音效。
