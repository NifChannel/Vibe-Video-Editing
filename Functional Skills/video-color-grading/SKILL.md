# 调色

用户只要求调色时，沿用已有剪辑时序、画幅和声音。创意风格以用户当前要求、已确认样片或项目风格为准。只说「调色」时先做自然校正和镜头一致性，保护肤色、商品或食物本色，保留有意的暖光、夜景和明暗层次。有明确风格依据或用户委托判断时可选定并执行，明显改变观感且方向未定时，先给同帧对照和少量可选预览。

## 1. 确认输入和交付色彩

- 确认要处理的源文件与时间段，以及成片需要的色域、传递函数和范围。常规网络 SDR 交付按项目的 Rec.709 路线处理，HDR 交付走独立色彩流程。
- 用 FFprobe 记录像素格式、位深、色彩原色、传递函数、矩阵、范围及 HDR 侧数据。结合相机设置、已有转码记录和代表帧确认格式。画面发灰或 10 位本身不足以判定 Log 或 HDR。标签缺失或可疑时先查证，无法确认就保留原始文件，把假设和试片区分开。
- 确认 SDR 仅在输入与目标不同的环节转换。Log 需要与实际相机曲线、色域和输出目标匹配的技术变换或官方 LUT。HLG/PQ 到 SDR 用经过验证的色调映射，HDR 保留按其交付规格检查位深和元数据。色彩标签描述实际信号，转换由滤镜或编辑器色彩管理完成。记录已经执行的技术变换，避免二次套用。

## 2. 选代表镜头，校正后匹配

1. 按相机及色彩配置、实际光线、场景和叙事目的分组。在已剪时间线抽取组内典型帧与难点帧，覆盖高光、暗部、肤色或主体本色。同一个源片跨灯光或曝光变化时可拆成多组。单镜头直接作为基准。
2. 选曝光有余量且主体颜色可靠的代表镜头。比较可正常显示的底片与候选结果，每轮只改一类参数。先稳定曝光与反差，再处理白平衡和色偏，最后微调饱和度。技术变换前后都检查是否裁掉高光，必要时在正确的工作色彩空间先做曝光调整。
3. 在基准镜头上试创意色调。技术 LUT 与创意 LUT 分开记录，按其输入要求安排顺序。确认肤色、食物、商品和关键中性色仍符合叙事，再把验证过的组内风格用作其他镜头的起点。
4. 逐镜调整相同主体或可比区域的亮度与颜色，再按剪辑顺序检查切换。读亮度波形查黑白端和层次，按需用 RGB 分量波形或矢量示波器查偏色和过饱和。整帧平均值受构图影响，判定以同一主体、同类光线和实际画面为主，保留跨场景应有的差别。

## 3. 应用并验收

- 先在短段验证实际滤镜链，再批量应用。项目内记录源片区间、组与基准镜头、输入到输出的色彩变换、滤镜参数、LUT 来源和版本、对照帧及例外。用现有清单或项目记录保存这些信息。另存输出以便重做。
- 通常在底片层完成技术转换和调色，再叠加字幕、贴纸、图表或品牌标志。按当前剪辑计划记录原片入出点、调色参数与效果范围，检查实际成片，并保留所需的调色配置和素材。
- 从实际导出复查代表镜头、组内切换和极端亮暗帧。检查肤色、关键物体色、高光纹理、暗部、色阶断层及字幕或图形是否被染色，再核对视频色彩标签、音画时长和完整解码。保留同时间码前后对照和必要的示波器证据。无法确认的输入色彩或观感写入交付记录。

本地探测、对照图、示波器与转码命令见 [FFmpeg 调色操作](references/ffmpeg.md)。
