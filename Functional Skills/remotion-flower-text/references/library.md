# 用户自选模板与项目内实现

本发布版不附带模板源码、预览、私人模板库、固定模板目录或 kinetic typography 快照。

用户可自行上网寻找可用的模板库，把仓库链接或组件交给 Codex。代理先看实际预览和源码，核对许可证、React/Remotion 版本及媒体/字体来源，按当前需要下载组件与依赖，在项目独立 vendor 目录适配。不要混入多个互相冲突的运行时，不默认运行外部仓库全部脚本。

没有模板时，按当前视频、稿件和安全区，用 Remotion 在本项目实现所需文字层与动效。先做真实底片上的代表短段，核对入场、稳定帧、最大缩放和退出，不根据模板名猜效果。

下载组件与本次派生效果默认只在项目中保留。明确要求保存为可复用库时再另存并记录参数、预览、来源、版本和许可证。字体安装和组件保存是不同操作，不因下载模板而修改系统字体。

基础环境由 Codex 自动安装，见 [统一依赖入口](../../../安装与外部依赖.md#captions)。
