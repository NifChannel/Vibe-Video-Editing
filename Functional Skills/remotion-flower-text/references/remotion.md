# Remotion 接入与验证

按 [字幕依赖](../../../安装与外部依赖.md#captions) 自动准备 Node、统一版本的 Remotion/React 和渲染浏览器。已有相关 Remotion skill 时可按需读取；没有时使用官方文档，不依赖未安装的全局 skill。

将实际文案、词级时码和图形参数写入项目 props，使用帧驱动动画，在项目内保留组件和入口。用户选定模板时按其真实接口适配；未选模板时可直接制作文字组件，不编造组件或套用旧项目文案。

字体加载完成后测量字宽和行高，检查长句、数字单位、最大缩放、阴影与出画边界。抽帧覆盖入场、稳定和退出，观看真实底片上的短视频。Alpha 层按交付需要验证透明通道，最终片仍按主技能完成音画、解码、帧数和响度检查。
