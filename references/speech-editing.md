# 原声口播整理：Qwen 基模与 F 流程

当视频需要整理原录口播、解说或采访时，除非用户明确指定其他方法，使用 **Qwen3-ASR-1.7B＋Qwen3-ForcedAligner-0.6B** 作为识别与对齐基模，执行[Qwen F 完整流程](speech-f-workflow.md)，并结合 [Blazerior](https://github.com/blazerior/videoediting-claude-skill) 的词表、停顿、EDL 与 FFmpeg 工具。先满足全部风格共同的口误、重复、呼吸、字音保护和成品回查要求，再应用[口播节奏选择](speech-rhythm.md)。用户当前要求优先；不把舒缓课程参数自动套给所有视频。

## 客户稿件的内容边界

遵循[统一入口](../SKILL.md)的稿件约定：已提供文字口播稿时，以客户原稿为内容基准，不将ASR识别结果或上游的文案优化建议写回原稿。校对只修转写与时码，删气口/误起等技术剪辑不能删改定稿中的有效词句、观点或顺序；录音与定稿不一致时先记录差异并沟通。不得为收紧时长改写或删减客户定稿。

客户提供文字稿或视频稿时，尽量不另加澄清、假设或免责提示；不自动继承上游信息卡/声明包装。TTS读音展开另存技术副本，原稿保留不变。

实际使用前按[运行环境](local-runtime.md)自动准备并验证独立 Python 与模型，不使用缺少依赖的环境或修改其他模型环境。

## 工具入口与适配范围

本 skill 的 [Blazerior 功能模块](../Functional%20Skills/blazerior-videoediting/SKILL.md)中仅保留 MIT 许可证、来源校验，以及实际需要的 dump_words.py、pauses.py、build.py。先读[工具说明](../Functional%20Skills/blazerior-videoediting/README.md)。

1. 用 scripts/qwen_transcribe.py 在已验证环境识别与对齐。将所需第三方工具复制到当前项目 tools，运行词表与停顿检查，再校对初稿和生成 EDL。空转写先排查，不把空结果交给词表工具。
2. 用 scripts/speech_evidence.py 做原录全覆盖声学补查。候选只作导航，不自动决定剪口。修订可复用来源、模型、配置和时间域一致的产物；从零制作时按原片重新处理。
3. 需要视频连同声音重切时，可在项目副本中适配 build.py base 的画幅、帧率、调色和缩放后执行。仅整理声音时按同一 EDL 使用项目内音频适配器，不让上游固定视觉参数改变已认可画面。
4. 记录实际工具、参数和 EDL；不把项目适配器描述成未实际调用的上游功能。媒体、模型、缓存和运行产物留在项目或独立运行目录。

逐句判断多余气口与有表达作用的停顿，字幕、画幅、调色和响度仍由当前项目决定。网页采集与图形制作按主入口选择所需工具。

## 剪辑目标：句内连贯，句间自然

- **词与词之间**：删除犹豫、冗长气口、无意义静音和废弃起音；保留真正的词与原意。多余气口可参考约80–150毫秒、以约0.1秒的衔接作为起点；这不是强制阈值，不机械扫描后删除所有低电平区间。
- **句子之间**：保留当前已自然的句间间隔、分句节奏和必要换气；不把整段话压成连珠炮。问句后、转折与结论前有表达作用的停顿保留。自然的短词间间隙无需再切。
- **重复与卡顿**：保留完整、流畅的一次表达，删除误起、重读的废弃片段；不改变意思或拼出原话没有的陈述。默认保留原录人声，不替换 TTS，不靠全段加速掩盖问题。
- **重排后的间隔**：一句内部缩短后，适当提前后续旁白，使原本自然的句间间隔保持接近；不能只固定每句起点，导致句内删掉的时间变成句间新增长空白。同时核对画面叙事与同期声，不机械移动所有后续事件。


## 定剪口与防止吞字

1. 优先使用未混入 BGM、未被强降噪或噪声门处理的原录音。先校对转写，特别是专名、句首句尾和废弃起音；转写仅用于导航，不能当作精确声学边界。
2. 查看实际波形、低电平区间，必要时看频谱并试听。中文送气、擦音与轻尾音常早于或晚于 ASR 标记；不能从“旗、细、是”等字的元音起点直接开剪，也不能把低电平的字音或字内闭塞当作静音。
3. 在真正的非语音保护区间裁切，保留起音、字尾和必要呼吸。可用约8–15毫秒短交叉淡化衔接；上游约30毫秒边缘淡化也需完全落在保护区间内。波形不支持安全收紧时，保留稍长间隙，不硬凑0.1秒。
4. 只修需要修的边界，不对连续语流逐词硬切，不用强噪声门造成时断时续，不对每个小片段分别重度降噪或归一化。连接后做连续、适度的人声处理与最终混音。

### 词尾波形检查

1. 定剪口时逐一核对所有会结束或淡出保留口播的音频出点，包括片尾。以实际出点和人声淡出起点为准，从未混配乐的原录提取边界前后的短窗（可从两侧各 0.5 秒开始）。结合词级对齐定位末词，再看波形确认尾音确实结束。轻尾音、送气或擦音不清楚时看频谱或试听，必要时扩窗。硬切、按帧取整后的出点和淡出起点都要落在词尾之后的安全区。存疑时往后留足原声。
2. 导出后用剪辑映射在最终文件的音轨中定位对应短窗，与原录波形对照，确认末词完整、淡化没有压掉尾音。配乐掩盖尾音时，结合按同一映射导出的人声轨复核。发现截断就修正剪口或淡出，再导出并复查。转写能识别出末词仍须完成这一步。
3. 用本地工具批量处理短窗，完整波形留在项目内。现有检查报告只记源片及成片时间码、检查结果和必要的修复或疑点。优先查看有疑问的局部图或音频。

## 剩余气口精修：切间隙与减呼吸分开处理

1. **候选与证据交叉核对**：先复用可靠的校对转写，运行词表、停顿工具作导航，再结合干净人声的 VAD、实际波形和短时能量（RMS），必要时看频谱并试听。ASR 的词间空档、VAD 的非语音和低 RMS 都可能包含轻声、尾音或数字内部停连，任何单项结果都不能直接批量转成剪点。先按语义区分句内冗余与句间自然停顿。
2. **缩短确有余量的间隙**：在字尾与下一字起音之外留保护区，再寻找安全的低能量裁切区；同步画面以整数帧定剪口，声音换算为对应采样点。只削掉多余部分，保留连贯所需间隙。小数、型号、单位和送气字特别保守；没有安全余量就不切，不能为了达到约 0.1 秒目标吞字。阈值和保护量按本次录音决定，不固定复用旧项目的 dB 数字或剪点。
3. **残留吸气声单独处理**：停顿长度自然但呼吸突出时，在词级边界、声学检测和波形共同支持的非语音区间，适量降低呼吸音量并做平滑增益过渡；需要时试听确认。保留真实换气，不能把所有 VAD 空档静音，也不把衰减应用到字音上。声音证据不充分时保留并记录，不以强噪声门掩盖。
4. **连接与同步**：短淡化或交叉淡化完全放在非语音保护区，避免点击声且不侵入辅音、字尾；若交叉淡化改变时长，计入 EDL。维护原片到新版的帧/采样映射，同步调整出镜口型、字幕时码、B-roll 入出点及素材使用区间；保持配乐连续，重新处理闪避、结尾淡出与整体混音。已接受的包装不因声音修订自动重做。
5. **检查并留记录**：保存候选、采用/保留理由、实际剪切与增益区间、EDL 和转写依据。检查剪口两侧完整字音、自然停顿、字幕与口型；复核完整解码、预期总帧数、音画时长和尾部，不因 FFmpeg 返回成功就判定全片完整。混用不同镜头参数时，先统一参数或妥善处理滤镜重置，防止帧计数/时码重置造成漏片。无法直接听辨时如实说明，声学与转写检查不等于人工听审。

## 画面、配乐与交付检查

- 旁白在 B-roll 下时，优先整理独立声音并沿用已接受的画面；不为藏口播剪口擅自重做视觉风格。出镜口播和同期对话若发生时间裁切，画面须同步处理，或用已获准的过渡画面遮盖；不能只剪声音造成口型失配。
- 更新人声与配乐闪避、尾部淡出和整体响度，保证剪辑后的旁白、BGM及结尾完整。沿用当前项目的音乐来源、字幕和素材约束。
- 留下源片段对应关系、EDL、词级转写与校对记录、必要的分轨/最终混音及检查报告；交付实际整理后的完整口播所在视频，若本次任务只要音频则交付音频。按用户要求保留旧版并另存修订。
- 复核剪口、句首句尾和所有重点句；有试听能力时试听纯人声与最终混音，并核对字音、呼吸、爆音、句间节奏与口型。用复核转写辅助确认未漏字或重复，但不能用它替代试听。
- 运行本 skill 的 `qa.py` 检查完整解码、帧数、音画长度和响度；有沿用画面的约定时验证画面一致性。无法直接听辨时如实标注，以波形、保护区间和转写补充检查，不声称已完成人工试听。
