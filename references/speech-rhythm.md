# 项目口播节奏选择

四项只选择声音节奏，识别、字音保护、语义与声学复核仍执行[Qwen F流程](speech-f-workflow.md)。口播选择不继承画面、字幕包装或配乐风格。

## 选择与优先级

先读当前工程 `video-editing.delivery.json` 的 `speech.style`，同时判断本次是否有口播参考样片、是否给出了明确口播要求。未点名风格时，仅从本次样片学习；没有样片和口播要求时才自动使用下面的默认预设。分辨率、字幕颜色等要求不算口播节奏指令。

优先级为本次明确口播要求 > 用户指定的非默认口播选择 > 本次口播参考 > 默认预设。用户要求和样片需要结合时先遵守要求，再参考样片。解析脚本只记录上下文并决定是否启用默认值，不自动理解自然语言或作语义剪辑判断。

| 选择 | 执行依据 |
|---|---|
| 自动 | 无口播跳过；有口播按本次要求、用户选择或样片处理，均无时采用默认预设。 |
| 默认风格（预选） | 无口播样片、无明确口播要求时，采用下表的默认节奏。 |
| 紧凑口播 | 沿用现有紧凑声音政策，更积极整理确认冗余的句内等待，保护数字、观点、字音及有作用的停顿。 |
| 舒缓口播 | 沿用现有舒缓声音政策，保留理解、列举和概念转换时间。 |

没有项目配置文件时，选择值仍为 `default`。当前发布版使用 `schema_version=2`，选择值为 `auto/default/compact/relaxed`，不新增交付配置字段。旧格式需先核对当前需求，再按本版格式重新生成；不自动改写旧文件，非法字段或版本须报错。

## 默认口播预设

启用条件：确认需要剪原录口播、解说或采访；本次没有口播参考样片；没有明确口播要求；项目选择为 `auto` 或 `default`。无需提供参考资料、来源索引或预先完成节奏统计。

风格目标：表达连贯、推进清楚、适度紧凑，普通分句保留自然换气，主题转换有更明显的空间。保留完整流畅的一遍，清理废弃重录、误起、卡顿和无意义重复；具有强调或解释作用的重复按句意判断。

| 停顿类型 | 默认目标 | 常用调整范围 |
|---|---:|---:|
| 句内分句、逗号衔接或列举 | 约0.25秒 | 0.2–0.4秒 |
| 完整一句结束，接下一句 | 约0.8秒 | 0.6–1.1秒 |
| 新话题、大段落转换 | 约2.2秒 | 1.9–2.6秒 |

执行时先按语义识别停顿类型，不能仅按标点或统一静音门限分配秒数。未断开的连续词组不为了凑时长新增气口。

- 超过常用范围的停顿逐处审查，确认冗余且有安全余量后收紧；长于范围不直接等于可删。
- 自然流畅的短衔接直接保留，不为满足下限而补静音。
- 强调、设问、包袱和理解停顿允许例外；在项目剪辑计划中记录保留理由。
- 字音完整、字头字尾和必要换气优先。时间处理与声音处理分开决定，处理突出呼吸或口腔杂声时按实际录音校准，不设通用固定衰减幅度。
- 检查保留语流内部的气口和衔接，对候选记录类型、原间隔、拟保留间隔、动作及理由，并落实到同一份 `edit-plan.json` 和源映射；不要求特定剪刀数量，不全段加速。

`assets/speech-rhythm.json` 保存实际输出给制作端的默认秒数与政策；`rhythm_policy.pause_targets_seconds` 中的 `target` 是首轮参考目标，`range` 是逐处复核的常用区间，都不是自动切点。声学候选、字音保护和成品回查继续按F流程执行。

## 解析命令

确认有口播、无口播参考、无明确口播要求时：

```powershell
python scripts/speech_settings.py --project "工程绝对路径" --speech-present yes --reference-present no --output "本次项目/work/speech-settings.json"
```

有口播参考时使用 `--reference-present yes`，输出要求先分析本次样片，不输出默认停顿秒数。有明确口播要求时传 `--speech-brief "本次口播剪辑要求"`，再据该要求制定具体计划；该参数只保存在解析结果，不回写用户的交付配置。

`speech-present` 和 `reference-present` 尚未确认时使用 `unknown`。省略参考状态默认为 `unknown`，暂不套用默认秒数，先确认任务材料。确认无口播时传 `--speech-present no` 并跳过整理。用户指定的紧凑或舒缓选择继续生效，不受这次默认预设替换。

解析输出中的 `default_preset_applied` 表示本次是否实际启用了默认预设；`planning_status` 和 `selection_reason` 说明应按要求、选择、样片还是默认值继续规划。没有选中具体节奏时 `rhythm_policy` 为null。读取参数成功不等于完成剪辑；任何选择都不表示新增旁白或TTS。
