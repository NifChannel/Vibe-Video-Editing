# 镜头规划与素材搜集

用于需要外部图片、视频、品牌资料或网页画面的剪辑任务。与 `SKILL.md` 的原稿保护、采用范围、去重和无额外片尾规则一起使用；项目素材、抓取记录和工具配置保存在项目内。

## 素材搜寻优先级

需要搜集素材时按下列顺序推进，不为增加素材数量而跳过镜头规划，也不强行填充无关画面：

1. **先做镜头规划**：逐句判断这句稿子需要什么类型的视觉证据或解释，明确对象、论点和画面用途，再开始找素材。
2. **按规划寻找相关资料**：寻找能够对应当句的相关视频、官方发布材料、官方图片、原始数据图表，或通过 OBS 等独立浏览器源录制相关网页。根据需要选择媒介，不只按品牌或关键词凑画面。
3. **资料无法满足时再原创**：第二级资料仍无法满足表达需要时，制作与当句对应的原创图解或示意动画，并在画面中明确标注“原创图解”“示意动画”等适当标识，不把它们冒充实拍或原始资料。
4. **资料和原创解释都不合适时保留口播**：保留主持人口播并优化构图，不强行填充无关 B-roll，也不为填画面而改稿。

这里的第三级标识按入口的原创图解与示意标识规则执行。第二、三级均不合适时，保留并优化主持人口播是正常选择；这不授权删除已经认可且仍有作用的讲解页。

## 从口播确定检索对象

选素材前先说明当前句子要解释什么，区分具体对象、论点与画面用途：

| 当前内容 | 优先寻找 | 容易错配的内容 |
|---|---|---|
| 品牌、产品、人物或事件 | 对象自己的产品图、演讲、发布页、主办方资料、真实人物照片 | 通用工厂冒充该公司现场，AI 人像代替真实人物 |
| 榜单名次、评测或数字 | 对应时点、指标和口径的原图、表格、发布记录 | 用生成游戏证明榜单第一，用一个月下载量解释累计下载量 |
| 具体能力或应用案例 | 正好展示该能力的演示及其上下文 | 同品牌的另一演示、视频后段无关的百科或浏览界面 |
| 原理、关系、数量类比 | 先找对应原理图、原始研究图或实物；资料不能满足时再按第三级制作明确标注的原创图解、2D/3D 示意动画 | 只因看起来像数学、代码或科技就插入 |
| 行业背景或转场 | 与当句行业和叙事有关的实拍 | 把背景画面作为某企业、某事件或具体数字的证明 |

公司名或“编程”“AI”等关键词相同，只能帮助找到候选，不能证明它适合当前这句话。记录画面承担的是证据、解释还是背景。稿件存在疑点时按入口规范沟通，不为了配图擅自改稿或补免责小字。

## 来源渠道与查找路径

按具体内容选择入口，不机械地先搜通用素材库：

| 用途 | 可用入口 | 取得后继续核对 |
|---|---|---|
| 公司、品牌、产品与发布会 | 公司官网、新闻中心、产品页、技术博客、官方公开演讲及宣传片 | 发布主体、型号、人物、场景、日期；真实拍摄与宣传动画的区别 |
| 模型、代码与开源生态 | 官方技术博客、[Hugging Face](https://huggingface.co/)、官方代码仓库、模型卡和发布记录 | 是否为官方账号，模型版本；演示内容与当前论点是否一致 |
| 评测与排名 | 榜单运营方，例如 [Arena](https://arena.ai/)；发布时的官方图表或公告 | 历史时点、榜单类别、样本或评测口径；不用最新排名冒充过去排名 |
| 人物、奖项和研究 | 奖项主办方、研究机构、大学新闻、作者主页和论文原文 | 人物身份、图注、原作者；机构文章内也可能含转载的媒体照片 |
| 行业背景与品牌文件 | [Pexels](https://www.pexels.com/)、[Mixkit](https://mixkit.co/)、[Unsplash](https://unsplash.com/)、[Wikimedia Commons](https://commons.wikimedia.org/) | 具体条目及对应许可、作者、付费或受限标识；不能凭站点名断定每个素材用途 |
| 社交与视频平台线索 | YouTube、bilibili、小红书等的官方账号或原始发布者 | 回溯发布者和原始出处，不把搬运、公开可见或可下载写成已授权 |

可参考公司官网、国际数学联盟等主办方、大学原文与官方模型仓库的路径；这些是来源类型，不固定绑定某家公司或旧项目。只记录真正检索、取得和采用的来源，区分候选、已下载、已采用及已替换。

检索到发布页后，可通过受支持的工具读取正文、图注和公开的图片、视频链接，再取得原始文件。网页记录与媒体文件建立关联；直接文件地址不能完全代替发布页。采用范围沿用入口规则，音乐与字体单独核对。

## 看过实际内容再入片

- 不能凭文件名、封面、网页描述或第一帧选择一个未经检查的源区间。短选段尽量完整查看；长片先用联系表定位，再核对实际选段的开头、中间、结尾和内容变化处。无法播放时按内容变化充分抽帧，并如实记录检查方式；缩略图只用于定位，不等于完整观看。
- 核对选段中真正出现的网页、人物、产品、字幕和画面；一个名为 dashboard 的文件，后段也可能是无关页面。同属官方宣传片的不同段落也可能承担完全不同的内容。
- 用 FFprobe 检查时长、帧率和流，用 FFmpeg 验证解码。可读取到总时长不代表文件下载完整。若只保留有效前缀，应记录处理方法、有效范围，并确保所有使用区间落在验证范围内。
- 检查历史工艺字幕、产品代次和发布时点，不把旧宣传片中的规格说成当年最新规格。保留必须的来源标识，不通过去台标、水印来规避采用限制。
- 裁切、拼贴和动效应帮助观众看清当前信息；不能通过排版把背景画面伪装成具体事件证据，或让图表表达原图没有的比较结论。

## 把网页浏览作为素材

网页录制属于第二级资料途径之一：可录制官网、产品页、模型仓库、榜单、论文或原始图表的浏览过程，选择直接对应镜头规划和口播的页面。

优先使用 OBS 的独立浏览器源采集网页界面；不使用独立 Chrome 无头截图或渲染，不把 Chrome 列为必装依赖。OBS 不可用时先说明情况，可用受支持的内置浏览器取得资料，不静默退回 Chrome 自动化。避免操作或捕获用户的日常浏览器；用户明确另行指定时按本次要求处理。OBS 使用独立场景、配置或必要时的便携实例，不改用户现有工作场景；只采集目标网页源，结束后释放本任务启动的实例和资源。

录制前检查页面是否加载完成、文字是否清晰、目标对象是否出现，以及弹窗、广告、浮层、登录信息和动态统计是否会干扰。确定浏览起点、移动范围和停留位置，让需要阅读的信息有足够停留。页面中的当期统计不能自动作为另一时期或另一统计口径的依据。

可使用正常滚动，或受支持的浏览器源视口移动、CSS 平移等方法形成浏览画面；不得篡改网页事实、排名和数字，也不把自制排版称为原网页截图。记录实际方法及画面取得时间。

录制命令或 API 返回成功后，仍需确认输出文件实际存在、有时长且能解码。普通录制失败时，可在支持的接口和当前授权范围内采集实际浏览器源帧，再按真实采样时间合成视频；不能把帧复制或插帧后的输出帧率写成原生采样帧率。先试录并检查代表画面，再投入批量采集。

需要操作工具时读取相应工具或技能说明；此方法不提供额外权限或绕过工具停止条件的授权。通用 skill 不保存项目端口、认证信息、便携目录或当前素材绝对路径。

## 匹配成片时间并保护已认可画面

每处插入对应当句原文、对象或论点，并说明为什么使用这张图或这个选段。优先根据语义边界切换，再安排节奏。合成后连同前后句检查，尤其是品牌切换、发布事件转入原理、案例转入榜单、统计转入口播评论的位置。

不能为填满时间窗或消除短空隙，盲目延长上个对象到下一句。按优先级调整相邻素材边界、寻找相关资料，资料无法满足时再作明确标注的原创图解或示意动画；两者均不适合则保留主持人口播并优化构图。已经认可的讲解页列入保护清单，插入新资料时检查其完整覆盖。

去重按入口规范和上述优先级执行：寻找新素材替换重复位置，不因去重连带删除已认可的正文图解；资料和原创解释均不适合时允许保留主持人口播。同一原片可以使用多个不同、互不重叠的源区间，记录变速后实际消耗的原片范围。同一图片改名、裁切、调色不能算新素材。Logo、标志性资料和关键人物照片允许必要复现，并记录理由和出现位置。图片、截图、裁切和组合版保留派生来源关系；内容哈希可辅助找相同文件，但不能识别所有重编码或改版式后的重复。例外复现按入口规范说明必要性。

## 台账的最少信息

字段名可沿用项目已有格式，避免为轻量任务增加无用表格；每处入片资料应能追溯到口播、原始来源和实际区间：

| 范围 | 记录信息 |
|---|---|
| 通用 | 素材标识、本地相对路径、原始发布页、发布主体、取得日期；有时效意义的资料另记发布日期和版本 |
| 内容与用途 | 当句原文、对象或论点、画面用途、对应理由、成片入出点、已采用或已替换状态 |
| 采用范围 | 许可或公开资料采用状态、依据链接、必要署名；不要将“官方公开”统一写成“免费商用授权” |
| 视频 | 原始来源标识、source_in/source_out、变速信息、有效可解码范围；统一时间单位和帧率 |
| 图片与派生物 | 内容标识或哈希、原图或父素材、组合与裁切关系、复用例外及理由 |
| 网页采集 | 页面 URL、取得时间、视口、录制方法、实际采样帧率与输出帧率、原始录像或帧记录 |
| 复核 | 实际查看或抽帧方式、匹配结论、需要替换的具体问题；未检查项如实标记 |
